## 👋 Hakkımda / About Me

🇹🇷 **Türkçe**

> Ölçeklenebilir kurumsal sistemler tasarlayan ve geliştiren bir **Senior Full-Stack Yazılım Mühendisiyim**. Backend tarafında **.NET / ABP Framework** ekosisteminde temiz mimari (Clean Architecture), Domain-Driven Design ve mikroservis yaklaşımlarıyla; frontend tarafında ise **React / Angular / TypeScript** ile uçtan uca ürünler ortaya koyarım.
